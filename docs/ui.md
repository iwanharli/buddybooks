# Tampilan Aplikasi

## Dashboard

Dashboard minimum:

- jumlah karya;
- jumlah edisi;
- jumlah eksemplar;
- jumlah koleksi;
- total modal;
- estimasi nilai terbaru;
- jumlah buku berdasarkan grade;
- jumlah buku berdasarkan kondisi;
- buku paling tua;
- buku paling bernilai;
- buku yang perlu inspeksi;
- buku dengan risiko aktif;
- wishlist prioritas tinggi;
- pembelian terbaru.

---

## Halaman Katalog

Fitur:

- pencarian judul;
- pencarian nama penulis;
- filter penerbit;
- filter tahun;
- filter edisi;
- filter kondisi;
- filter collection grade;
- filter status;
- filter lokasi;
- tampilan kartu;
- tampilan tabel;
- ekspor CSV atau Excel.

---

## Halaman Detail Buku

Susunan yang disarankan:

1. Identitas karya.
2. Informasi edisi.
3. Identitas eksemplar.
4. Galeri foto.
5. Kondisi terbaru.
6. Riwayat kondisi.
7. Akuisisi dan modal.
8. Valuasi.
9. Provenance.
10. Lokasi.
11. Catatan internal.

---

## Halaman Inspeksi

Fitur:

- form pemeriksaan;
- checklist;
- unggah foto kerusakan;
- skor otomatis;
- rekomendasi;
- jadwal inspeksi;
- perbandingan dengan laporan sebelumnya.

---

## Halaman Wishlist

Fitur:

- urut berdasarkan prioritas;
- filter anggaran;
- status pencarian;
- penjual potensial;
- tautan sumber;
- tombol konversi menjadi eksemplar.

---

# Pencarian dan Filter

Pencarian dasar:

- judul;
- judul asli;
- kode karya;
- kode edisi;
- kode inventaris;
- barcode;
- nama penulis;
- penerbit;
- percetakan;
- ISBN.

Filter:

- rentang tahun;
- bahasa;
- jenis karya;
- status eksemplar;
- tingkat koleksi;
- kelengkapan;
- kondisi;
- lokasi;
- kepemilikan dust jacket;
- limited edition;
- harga beli;
- nilai pasar;
- risiko aktif.

Pengembangan pencarian lanjutan dapat menggunakan full-text search dan normalisasi nama.
